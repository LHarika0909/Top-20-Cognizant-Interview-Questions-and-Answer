# Top 20 Cognizant Interview Questions

## 1. Tell me about yourself.

**Answer:**

Introduce yourself professionally by mentioning:

- Educational background
- Technical skills
- Academic projects
- Certifications
- Career goals

---

## 2. What is Object-Oriented Programming (OOP)?

**Answer:**

OOP is a programming paradigm based on objects.

The four pillars are:

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

## 3. What is the difference between C, C++, and Java?

| Feature | C | C++ | Java |
|---------|---|------|------|
| Paradigm | Procedural | Object-Oriented | Object-Oriented |
| Platform | Platform Dependent | Platform Dependent | Platform Independent |
| Memory Management | Manual | Manual | Automatic (Garbage Collection) |

---

## 4. What is SQL?

**Answer:**

SQL (Structured Query Language) is used to communicate with relational databases for:

- Creating tables
- Inserting records
- Updating data
- Deleting records
- Retrieving information

---

## 5. Difference between DELETE, TRUNCATE, and DROP.

| DELETE | TRUNCATE | DROP |
|---------|-----------|------|
| Removes rows | Removes all rows | Deletes entire table |
| Can rollback | Cannot rollback (generally) | Cannot rollback |
| Table exists | Table exists | Table removed |

---

## 6. What is a Primary Key?

**Answer:**

A Primary Key uniquely identifies every record in a table.

Properties:

- Unique
- Not NULL
- Only one primary key per table

---

## 7. Explain Normalization.

**Answer:**

Normalization is the process of organizing database tables to reduce redundancy and improve data integrity.

Common forms:

- 1NF
- 2NF
- 3NF
- BCNF

---

## 8. What is a Foreign Key?

**Answer:**

A Foreign Key establishes a relationship between two database tables.

It maintains referential integrity.

---

## 9. Explain Stack and Queue.

| Stack | Queue |
|--------|-------|
| LIFO | FIFO |
| Push/Pop | Enqueue/Dequeue |
| Last element removed first | First element removed first |

---

## 10. What is the difference between Array and Linked List?

| Array | Linked List |
|--------|-------------|
| Fixed size | Dynamic size |
| Fast indexing | Sequential access |
| Contiguous memory | Non-contiguous memory |

---

## 11. What is Time Complexity?

**Answer:**

Time Complexity measures how the execution time of an algorithm grows with input size.

Examples:

- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n²)

---

## 12. Explain Binary Search.

**Answer:**

Binary Search finds an element in a sorted array by repeatedly dividing the search space into halves.

Time Complexity:

```
O(log n)
```

---

## 13. Difference between Process and Thread.

| Process | Thread |
|----------|---------|
| Independent execution | Lightweight execution unit |
| Separate memory | Shared memory |
| More overhead | Less overhead |

---

## 14. What is Deadlock?

**Answer:**

Deadlock occurs when two or more processes wait indefinitely for resources held by each other.

Necessary conditions:

- Mutual Exclusion
- Hold and Wait
- No Preemption
- Circular Wait

---

## 15. What is an API?

**Answer:**

API (Application Programming Interface) enables communication between different software applications.

Example:

A weather application fetching weather information from a remote server.

---

## 16. What is HTTP?

**Answer:**

HTTP (HyperText Transfer Protocol) is the protocol used for communication between web browsers and web servers.

Common methods:

- GET
- POST
- PUT
- DELETE

---

## 17. Difference between GET and POST.

| GET | POST |
|------|------|
| Retrieves data | Sends data |
| Data in URL | Data in request body |
| Less secure | More secure |

---

## 18. Explain Exception Handling.

**Answer:**

Exception Handling manages runtime errors gracefully.

Common keywords (Java):

- try
- catch
- finally
- throw
- throws
